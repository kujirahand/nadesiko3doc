●『[[元号データ:plugin_system/元号データ]]』の詳しい解説

和暦変換に使用されている、明治以降の元号とその改元日の、JSONデータです。
{{{#nako3
元号データをJSONエンコード整形して表示。
### 表示結果: [
###   {
###     "元号": "令和",
###     "改元日": "2019/05/01"
###   },
###   {
###     "元号": "平成",
###     "改元日": "1989/01/08"
###   },
###   {
###     "元号": "昭和",
###     "改元日": "1926/12/25"
###   },
###   {
###     "元号": "大正",
###     "改元日": "1912/07/30"
###   },
###   {
###     "元号": "明治",
###     "改元日": "1868/10/23"
###   }
### ]
}}}

配列なので、要素を取り出して使えます。

{{{#nako3
元号データ[0]["元号"]を表示。
元号データ[0]["改元日"]を表示。
### 表示結果: 令和
### 2019/05/01
}}}
