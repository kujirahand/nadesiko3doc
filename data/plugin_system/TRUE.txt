▲解説

真偽型の真(TRUE / true)を表す定数です。
なでしこ3では、大文字の「TRUE」だけでなく、小文字の「true」も同じ真を表す定数として利用できます。

▲利用例

{{{#nako3
TRUEを表示 # true
trueを表示 # true
TRUEを真偽判定して表示。# 真
trueを真偽判定して表示。# 真
### 表示結果: true
### true
### 真
### 真
}}}
