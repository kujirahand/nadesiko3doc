▲説明

指定した配列、辞書型変数、または文字列の要素数を返します。
文字列を指定した場合は、サロゲートペア（絵文字など）も1文字として数えるので、
「[[文字数:plugin_system/文字数]]」と同じ値になります。

▲利用例

配列の要素がいくつあるかを返します。

{{{#nako3
# 配列の要素数
A＝[1, 2, 3, 4, 5]
Aの要素数を表示。# → 5

# 辞書型のキー数
D＝{"名前": "太郎", "年齢": 20}
Dの要素数を表示。# → 2

# 文字列の長さ
S＝「こんにちは」
Sの要素数を表示。# → 5

# サロゲートペアも1文字として数える
「🐱🐶」の要素数を表示。# → 2
### 表示結果: 5
### 2
### 5
### 2
}}}

▲利用上の注意点 - 配列と辞書を混ぜると危険

配列に文字列キーを指定して値を代入した場合、その値にはキーでアクセスできますが、配列の要素にはなりません。そのため、「要素数」には数えられません。キーと値の組を数えたい場合は、辞書型変数を使ってください。

{{{#nako3
# 無理矢理配列にキーを設定するうまくいかない例
A＝[]  # ← 辞書でなく空の配列を作成
A＠「あ」＝「い」
A＠「あ」を表示。 # → い
Aの要素数を表示。 # → 0
### 表示結果: い
### 0
}}}

{{{#nako3
# 正しく動く例
A＝{} # 空の辞書を作成
A＠「あ」＝「い」
A＠「あ」を表示。 # → い
Aの要素数を表示。 # → 1
### 表示結果: い
### 1
}}}
