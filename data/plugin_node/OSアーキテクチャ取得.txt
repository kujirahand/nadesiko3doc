●『[[OSアーキテクチャ取得:plugin_node/OSアーキテクチャ取得]]』の詳しい解説

実行中のCPUアーキテクチャを返します。Node.js専用の命令です。内部では `process.arch`（`os.arch()` と同じ値）を利用しています。

主な値は以下の通りです。

| 値 | 説明 |
| --- | --- |
| arm64 | Apple Silicon / 64bit ARM |
| x64 | 64bit Intel/AMD |
| ia32 | 32bit |

▲利用例

{{{
# アーキテクチャを表示する
OSアーキテクチャ取得して表示。
}}}
