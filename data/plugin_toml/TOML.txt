▲TOMLとは

TOML(Tom’s Obvious, Minimal Language)は設定ファイルを書くためのフォーマットです。「人間にとって読みやすく、機械にとって扱いやすい」ことを強く意識して作られたものです。

{{{#nako3(rows=10)
# TOML文字列をパースする方法
データ=「
# -----------------------
[setting]
foo = 3
bar = 5
# -----------------------
」
データをTOML取得して、Ｆに代入。
ＦをJSONエンコード整形して表示。
### 表示結果: {
###   "setting": {
###     "foo": 3,
###     "bar": 5
###   }
### }
}}}

JSONデータをTOML文字列として出力する例：

{{{#nako3(rows=10)
# JSONデータをTOMLに変換して出力する
データ={"setting": { "foo": 3, "bar": 5 } }
データをTOML変換して表示。
### 表示結果: [setting]
### foo = 3
### bar = 5
}}}

▲利用例 - テーブルや配列を含むTOML

TOMLでは`[テーブル名]`で入れ子構造(テーブル)を、`[ ]`で配列を表現できます。

{{{#nako3(rows=10)
データ=「name = "なでしこ"
langs = ["JS", "PHP"]

[owner]
name = "kujirahand"」
データをTOML取得して、Ｆに代入。
(Ｆ["name"])を表示。
(Ｆ["langs"][0])を表示。
(Ｆ["owner"]["name"])を表示。
### 表示結果: なでしこ
### JS
### kujirahand
}}}
