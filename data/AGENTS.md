# AGENTS.md

このリポジトリは、なでしこ3のマニュアルです。
命令一覧とライブラリのマニュアルです。
チュートリアルを含んでいます。

## フォルダ構成

```md
- AGENTS.md                 --- 本ファイル
- FrontPage.md              --- トップページ
- nako3commands.db          --- cnako/wnako/各種プラグインの命令一覧(SQLite)
- gonako-commands.db        --- gonakoの命令一覧(SQLite)
+ .plugins/                 --- konawiki3のローカルプラグイン
|   - nako3doc.inc.php      --- なでしこ3マニュアルのヘッダに表示するプラグイン
|   - nako3doc2kona.inc.php --- 命令一覧をカナ順に表示するプラグイン
+ .meta/                    --- konawiki3のメタ情報(自動生成のため編集禁止)
+ plugin_system/            --- plugin_systemに属する命令マニュアルの一覧
|   - 表示.txt              --- `表示`関数のマニュアル
|   - 言.txt                --- `言`関数のマニュアル
|   - ...
```

## 編集してはいけないもの

- `konawiki3/` `private/` `cache/` `attach/` は編集しません。
- `data/.meta/` は、GitHub Actions(`.github/workflows/update-meta.yml`)が自動生成します。手で編集しません。
- `nako3commands.db` と `gonako-commands.db` は、`script/cmd2db.nako3` で生成します。直接編集しません。

## ファイルの形式

- 文字コードはUTF-8、改行コードはLFで統一します。
- ファイル名の末尾に空白を入れません(例: `__DEBUG強制待機 .txt` のような名前は作らない)。

## マニュアルの書き方

KonaWiki記法のテキストで書かれています。

### KonaWiki記法について

```text
■ 大見出し

● 中見出し

▲ 小見出し

- 箇条書き1
- 箇条書き2
- 箇条書き3

・箇条書き1
・箇条書き2
・箇条書き3

{{{#nako3
※ ここに、なでしこ3(Web版)のプログラムコードを書きます
### 表示結果: (ここにプログラムの表示結果を書く)
}}}

{{{
※ ここに、なでしこ3(Node版)のプログラムコードを書きます
}}}

[[リンクラベル:URL]]

#image(画像のURL,*キャプション,@URL)
```

## 命令コマンドのファイル名

なでしこの関数や定数は、`data/`フォルダ以下に保存されます。
次の書式のファイル名になります。

```md
{プラグイン名}/{関数名}.txt
{プラグイン名}/{定数名}.txt
```

(例) なお、関数「文字数」は、標準プラグイン(plugin_system)に属しており、ファイル名は次のようになります。

```md
plugin_system/文字数.txt
```

### 命令ファイルの章立て

命令(関数・定数)のファイルは、次の章立てで書きます。見出しは `▲` に統一します。

```text
▲説明

(命令の説明)

▲利用例

サンプルコード1の説明

{{{#nako3
(サンプルコード1)
### 表示結果: (期待する表示結果)
}}}

サンプルコード2の説明

{{{#nako3
(サンプルコード2)
### 表示結果: (期待する表示結果)
}}}

▲参考

- [[plugin_system/要素数]]
- [[plugin_system/LEN]] --- 説明(任意)
```

### リンクの書き方

- 命令へのリンクは `[[プラグイン名/命令名]]` と書きます。(例) `[[plugin_system/要素数]]`
- 表示名を変えるときは `[[表示名:プラグイン名/命令名]]` と書きます。(例) `[[表示:plugin_system/表示]]`
- 「▲参考」では、1行に1リンクを `- ` で箇条書きにします。説明を付けるときは、リンクの後ろに ` --- 説明` を続けます。

### DocTestについて

プログラムの最下行に、### 表示結果: 15のように、期待する表示結果を記述します。DocTestは、マニュアルのサンプルコードが正しく動作するかを確認するためのテストです。複数行の結果であれば、次のように記述します。

```text
{{{#nako3
「あ{改行}い」と表示。
### 表示結果: あ
### い
}}}
```

DocTestは、次のコマンドで実行します。

```sh
gonako doctest <path>
```

次のような、結果を確認できないサンプルコードでは、`### 表示結果:` を省略できます。省略するときは、コメントに `# → 7` のように期待値を書きます。

- ブラウザ依存の命令(`plugin_browser` など)
- ファイルやネットワークを操作する命令
- 実行するたびに結果が変わる命令

## チュートリアル

チュートリアルは、以下のファイル名に保存されます。

```md
チュートリアル/*.txt
```

## 文法リファレンス

以下のファイル名に保存されます。

```md
文法リファレンス/*.txt
```

## 文体

文体は、基本的に「です」「ます」調です。簡潔さを保ちながら、丁寧な文章を心がけてください。

- 本マニュアルは「なでしこ3」用です。「なでしこ」とは書かず、「なでしこ3」と書きます。
- 半角英数字と日本語の間には、半角スペースを入れます。(例) `Web ブラウザ` `JavaScript の配列`
  - ただし、固有名詞の「なでしこ3」や、`「`や`」`などの括弧・句読点の前後、コードブロックやインラインコードの中は対象外です。

## includeプラグインの役割

`#include(path)` とだけ書かれたファイルは、別名(エイリアス)です。そのファイルは変更しないようにします。
