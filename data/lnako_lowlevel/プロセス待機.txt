▲説明

起動した子プロセス HANDLE の終了を待機し、終了コード exitCode と終了シグナル番号 signal を持つ辞書を返します。POSIX の waitpid に相当します。正常終了時は signal が null になり、POSIX 環境でシグナルにより終了した場合は exitCode が 128 + signal、signal がそのシグナル番号になります。

▲仕様

- 対応環境: [[lnako]] 専用 (Web ブラウザ版 [[wnako]] や Node.js 版 [[cnako]] では動作しません)
- プラグイン: [[lnako_lowlevel]]
- 分類: プロセス・端末制御
- 助詞: HANDLEを/HANDLEの
- 戻り値: `waitResult`
- 実装状況: 実装済み
- 機能 ID (capability): `argv_spawn`
- 発生し得るエラー: EBADF, EINVAL, ENOTSUP

▲利用例

{{{#nako3
PROC = [「true」]をプロセス起動。
RES = PROCのプロセス待機。
RES[「exitCode」]を表示。
### lnako表示結果: 0
}}}
