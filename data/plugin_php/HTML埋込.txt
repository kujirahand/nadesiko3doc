▲説明

文字列Sの中に、辞書型データDICの値を埋め込んで返します。テンプレート文字列を組み立てる際に使う命令です。

書式は、Sの中に`[[変数名]]`のように書いておくと、DICの中から対応するキーの値に置き換えられます。置き換え時には自動的に[[plugin_php/HTML変換]]と同じ処理でHTMLエスケープされるため、安全にユーザー入力を埋め込めます。

キーの後ろに`|`(パイプ)で修飾子を付けると、変換方法を変更できます。

- `[[変数名|raw]]`: HTML変換せずにそのまま埋め込む
- `[[変数名|br]]`: 改行(`\n`)を`<br>`に変換してから埋め込む(HTML変換は行われる)
- `[[変数名|書式]]`: 書式に従って値を変換してから埋め込む。書式には`sprintf`の書式(例:`%03d`、`%02X`)か、`date`(`Y/m/d`形式)・`time`(`H:i:s`形式)・`datetime`(`Y/m/d H:i:s`形式)のいずれかを指定できる

助詞は「Sに」(または「Sへ」)「DICを」の順です。この命令はなでしこ3PHP(phpnako)専用です。

▲利用例

{{{
# 通常の埋め込み(自動的にHTML変換される)
「こんにちは[[name]]さん」に{"name": "<太郎>"}をHTML埋込して表示。
# → こんにちは&lt;太郎&gt;さん

# HTML変換せずにそのまま埋め込む
「本文:[[body|raw]]」に{"body": "<b>強調</b>"}をHTML埋込して表示。
# → 本文:<b>強調</b>

# sprintf書式で0埋めする
「番号:[[num|%03d]]」に{"num": 7}をHTML埋込して表示。
# → 番号:007

# 日付書式に変換する
「登録日:[[ts|date]]」に{"ts": 1625138536}をHTML埋込して表示。
# → 登録日:2021/07/01
}}}
