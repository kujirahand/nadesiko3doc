●配列変数とは

配列変数を使うと一つの変数の中に複数の値を代入できます。番号を使って値を出し入れします。

●配列変数の使い方

{{{
[書式]
# 初期化
変数名＝[]

# 値を代入
変数名[要素番号] = 値
変数名＠要素番号 = 値

#値を参照
変数名[要素番号]を表示
変数名＠要素番号を表示
}}}

・（メモ1）要素番号は0から始まります。
・（メモ2）角括弧 [ ... ] を、全角角括弧【...】で記述もできます。


●簡単な利用例

以下は配列変数Aを作成し、値を代入したり参照したりする例です。

{{{#nako3
# 初期化
A= []
# 値を代入
A@0 = 30
A@1 = 50
A@2 = 80
# 値を参照
A@2を表示。
}}}

●JSON記法を使って配列を初期化する

JSON記法を使って配列を初期化できます。

{{{#nako3
# JSON記法で初期化
A = [30, 50, 80]

# 内容を参照
A@2を表示。
}}}

●添字に範囲を指定して部分配列を取得する

添字に[[範囲オブジェクト:文法/範囲]]を指定すると、配列の一部を取り出したスライスを取得できます。位置は 0 から始まり、先頭の位置を含み、末尾の位置は含みません。

{{{#nako3
A=[0,1,2,3,4,5,6]
A_SUB=A[0…3]
A_SUBをJSONエンコードして表示。
区間=2…5
A[区間]をJSONエンコードして表示。
### 表示結果: [0,1,2]
### [2,3,4]
}}}

範囲に指定する負の位置は末尾から数えます。範囲が配列を超えた部分は切り詰めます。先頭と末尾が同じ位置の場合や、先頭が末尾より後の場合は、空の配列を返します。この負の位置の扱いは範囲指定に対するもので、配列の単一添字「A[-1]」で最後の要素を取得することはできません。

{{{#nako3
A=[0,1,2,3,4]
A[-3…-1]をJSONエンコードして表示。
A[-99…99]をJSONエンコードして表示。
A[2…2]をJSONエンコードして表示。
### 表示結果: [2,3]
### [0,1,2,3,4]
### []
}}}

スライスは浅いコピーです。取り出した配列の要素を入れ替えても元の配列は変わりません。ただし、要素が配列や辞書の場合、その要素自体は元の配列と共有されます。

{{{#nako3
A=[0,1,2,3]
B=A[0…2]
B[0]=99
AをJSONエンコードして表示。
BをJSONエンコードして表示。
### 表示結果: [0,1,2,3]
### [99,1]
}}}

なお、既存の[[plugin_system/参照]]命令は末尾の位置を含みます。「A[0…3]」は最初の 3 要素ですが、「Aの0…3を参照」は最初の 4 要素を返します。

●繰り返し文と組み合わせる

以下は配列変数Aを作成し、[[繰り返し文:文法/繰返]]を使って内容を全部画面に表示します。

{{{#nako3
# 初期化
A= [30, 50, 80]

# 値を全部出力
Nを0から2まで繰り返す
　　A@Nを表示
ここまで
}}}

- (参考) [[繰り返し文:文法/繰返]]

●反復文と組み合わせる

また、反復を使うと要素数にかかわらず手軽に処理できます。

{{{#nako3
A=[30,50,80]
Aを反復
　　対象を表示
ここまで。
}}}

●二次元配列変数

配列変数の中に配列変数を代入することで二次元配列変数を表現できます。二次元配列変数は表を作成するのに役立ちます。CSV操作と組み合わせることで、事務データの処理などに使えます。

- (参考) [[plugin_csv/CSV操作]]

二次元配列変数の要素にアクセスするには、下記のように記述します。添字の A と B には、数値や変数を指定できます。

{{{
[書式]
# [ ... ] を使う場合
変数[A][B] = 値。
変数[A][B]を表示。

# [ ... ] の中でカンマ区切りにする場合
変数[A,B] = 値。
変数[A,B]を表示。

# @ を使う場合
変数@A@B = 値。
変数@A@Bを表示。
}}}

以下、利用例です。

{{{#nako3
A= [[0,1,2], [3,4,5], [6,7,8]]
#
A[1][1] = 100
A[1][1]を表示
#
A@2@2=100
A@2@2を表示
### 表示結果: 100
### 100
}}}

▲二次元配列変数で＠を使う時の注意

「X@A@B」は左から順にアクセスし、「X[A][B]」と同じ意味になります。インデックスに変数を指定する場合も、この形式を使えます。

{{{#nako3
変数のXは[[1,2],[3,4]]。
変数のAは0。
変数のBは1。
X@A@Bを表示。
X[A][B]を表示。
X[A,B]を表示。
# 変数を添字に使って値を代入する
X@A@Bは100。
X[A][B]を表示。
### 表示結果: 2
### 2
### 2
### 100
}}}

「X@A,B」のように、@ の後ろをカンマで区切って多次元配列を指定する形式は使えません。「X@A@B」「X[A][B]」「X[A,B]」のいずれかを使ってください。([[参考#2396:https://github.com/kujirahand/nadesiko3/issues/2396]])

インデックス自体を配列の要素にしたい場合は、「X@(A@B)」または「X[A@B]」のように括弧で囲みます。


●カッコで囲んだ配列要素へのアクセスと代入

「(A@0)@1」のように、丸カッコで囲んだ配列要素を参照したり、代入先に指定したりできます。書き方と利用例は、[[カッコで囲んだ配列要素へのアクセスと代入:文法/配列変数-カッコ要素の配列]]を参照してください。
