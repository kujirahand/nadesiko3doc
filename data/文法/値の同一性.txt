■値の同一性について

なでしこ3で値を比べる方法には、「同じものかどうか（同一性）」を比べる方法と、「内容が同じかどうか」を比べる方法があります。配列や辞書のようなオブジェクトでは、この 2 つは違う結果になります。ここでは、命令『[[等:plugin_system/等]]』『[[一致:plugin_system/一致]]』と、演算子 `=` `===` の違いをまとめます。

●『等』は同一性を比べます

命令『[[等:plugin_system/等]]』は、JavaScript の `===` と同じ厳密な比較です。数値・文字列・真偽値・未定義といった基本的な値（プリミティブ値）は、型と値が同じときに等しくなります。配列・辞書・関数は、内容が同じでも、別々に作ったものは等しくありません。同じものを代入した変数どうしだけが等しくなります。反対の結果を返す命令が『[[等無:plugin_system/等無]]』です。『等』は「（AがBと等しい）」とも書けます。

{{{#nako3
A=[1,2,3]
B=[1,2,3]
(AとBが等)を表示。
C=A
(AとCが等)を表示。
### 表示結果: false
### true
}}}

演算子 `===` も同じ厳密な比較です（反対は `!==`）。

{{{#nako3
A=[1]
B=[1]
(AがBと等しい)を表示。
(A===B)を表示。
### 表示結果: false
### false
}}}

●『一致』は内容を比べます

命令『[[一致:plugin_system/一致]]』は、両辺がオブジェクト（JavaScript の typeof が "object" になる、配列・辞書・NULL）のとき、内容が同じかどうかを比べます。それ以外の値については、『等』と同じ厳密な比較です。反対の結果を返す命令が『[[不一致:plugin_system/不一致]]』です。

{{{#nako3
A=[1,2,3]
B=[1,2,3]
(AとBが一致)を表示。
(AとBが等)を表示。
D={「x」:1}
E={「x」:1}
(DとEが一致)を表示。
(DとEが等)を表示。
([1,2]と[1,3]が不一致)を表示。
### 表示結果: true
### false
### true
### false
### true
}}}

内容の比較は JSON 表現の一致で決まります。そのため、辞書ではキーの並び順が違うと一致しません（ただし、『1』のような数字だけのキーは、本家 JavaScript では数値順に並び替えて比べます）。また、循環参照を持つ値をオブジェクトと『一致』で比べると、JSON への変換ができないためエラーになります（『等』は参照だけを見るのでエラーになりません）。なお、値が未定義のキーは JSON に含まれないため、`{「x」:未定義}` と `{}` は一致します。

{{{#nako3
A={「x」:1,「y」:2}
B={「y」:2,「x」:1}
(AとBが一致)を表示。
### 表示結果: false
}}}

●演算子 `=` は型を変換して比べます

演算子 `=`（`==` も同じ）は、型の違う値どうしを変換してから比べる緩い比較です。ただし、両辺がオブジェクトのときは文字列に変換せず、同一性（同じものかどうか）で判定します。片方だけがオブジェクトのときは、そのオブジェクトを基本的な値に変換してから比べます。なお、NULL と未定義は例外で、`=` では互いに等しくなります（ほかの値とは等しくなりません）。『等』で比べると false です。

次の例の A と B は、文字列にするとどちらも `[object Object]` になりますが、両辺がオブジェクトなので文字列化せずに判定され、false になります。

{{{#nako3
A=[「[object Object]」]
B={}
(A=B)を表示。
([1]=1)を表示。
([1]=「1」)を表示。
C={}
(C=「[object Object]」)を表示。
(NULL=未定義)を表示。
### 表示結果: false
### true
### true
### true
### true
}}}

●基本的な値（プリミティブ値）の比較

基本的な値については、『等』と『一致』はどちらも型と値の厳密な比較です。型を変換して比べたいときは演算子 `=` を使います。

{{{#nako3
(1と1が等)を表示。
(1と「1」が等)を表示。
(1=「1」)を表示。
(1と「1」が一致)を表示。
(「abc」と「abc」が一致)を表示。
(1と2が等無)を表示。
### 表示結果: true
### false
### true
### false
### true
### true
}}}
