●JSON記法とは

JSON記法(辞書型リテラル式)とは、プログラムの中にJSONデータを直接記述できる記法のことです。

{{{#nako3
# 配列変数を初期化
A = []
# 辞書型変数を初期化
D = {}
}}}

簡単に配列変数を要素付きで初期化できます。

{{{#nako3(rows=10)
# 配列を直接記述できる
A = [0,1,2,3,4]
# 中身をチェックしよう
A をJSONエンコードして表示。
A[2] を表示。
A[0…3] をJSONエンコードして表示。
### 表示結果: [0,1,2,3,4]
### 2
### [0,1,2]
}}}

簡単に辞書型変数を要素付きで初期化できます。

{{{#nako3(rows=8)
# 辞書を直接記述できる
D = {"名前": "ネコ", "色": "茶色"}
# 中身をチェックしよう
D をJSONエンコードして表示。
D["名前"] を表示。
### 表示結果: {"名前":"ネコ","色":"茶色"}
### ネコ
}}}

●辞書型の省略記法について

辞書型のリテラルを記述する際、簡易的にキーだけを書いてキーと値を指定できます。

{{{#nako3(rows=12)
# ケース1: 数値キー
{1:10} をJSONエンコードして表示。

# ケース2: 変数の省略記法
a=1
{a} をJSONエンコードして表示。

# ケース3: 数値のみ
{10} をJSONエンコードして表示。
### 表示結果: {"1":10}
### {"a":1}
### {"10":10}
}}}
