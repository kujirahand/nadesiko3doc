●説明

設定辞書Aに従って、ウィンドウハンドルBが表すウィンドウを変更します。現在指定できるハンドルは、メインウィンドウを表すシステム定数[[gonako/母艦]]です。この命令はネイティブウィンドウを持つ`gonako-gui`で使用できます。

設定辞書には、変更したい項目だけを指定します。指定しなかった項目は変更しません。

- `サイズ`: `[幅,高さ]`の配列で指定します。幅と高さには正の整数を指定します。
- `位置`: `「中央」`または`[X,Y]`の配列で指定します。座標は画面の左上を基準とし、複数ディスプレイの配置によっては負の整数も指定できます。
- `状態`: `「通常」`、`「最大化」`、`「最小化」`、`「全画面」`のいずれかを指定します。
- `タイトル`: タイトルバーに表示する文字列を指定します。
- `サイズ変更可`: ユーザーによるサイズ変更を許可する場合は真、固定する場合は偽を指定します。

設定値やウィンドウハンドルが不正な場合は、実行時エラーになります。アスペクト比を固定する機能は、この命令には含まれていません。

●利用例

母艦を640×480ピクセルに変更し、画面の中央へ移動します。

{{{#nako3
設定＝{
　"サイズ":[640,480],
　"位置":"中央",
　"タイトル":"見本アプリ"
}
設定で母艦のウィンドウ変更
}}}

母艦を最大化します。

{{{#nako3
{"状態":"最大化"}で母艦のウィンドウ変更
}}}

最大化または全画面表示から通常の状態へ戻します。

{{{#nako3
{"状態":"通常"}で母艦のウィンドウ変更
}}}

●起動時の設定

HTMLプロジェクトや単一実行ファイルへ変換するプロジェクトでは、同じ設定辞書をプロジェクトフォルダの`index.json`へ記述できます。`index.json`はウィンドウを表示する前に適用されるため、起動後にサイズを変更する場合のちらつきを防げます。

```json
{
  "サイズ": [640, 480],
  "位置": "中央",
  "状態": "通常",
  "タイトル": "見本アプリ",
  "サイズ変更可": true
}
```
