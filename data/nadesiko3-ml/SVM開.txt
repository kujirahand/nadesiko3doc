▲説明

機械学習のアルゴリズム「SVM(サポートベクターマシン)」をオブジェクトOPTIONのパラメータで開きます。以降、『学習』『予測』などの命令で、このSVMを利用した機械学習が行えます。

OPTIONには次のようなキーを指定できます。

- type ... SVMの種類(例:'C_SVC'など)
- kernel ... カーネルの種類(例:'RBF'など)
- gamma ... カーネルのパラメータ
- cost ... コストパラメータ

▲利用例

{{{#nako3
!「nadesiko3-ml」を取り込む

XORデータ=[[0, 0], [1, 1], [1, 0], [0, 1]]
XORラベル=[0, 0, 1, 1]

{'kernel':'RBF', 'type':'C_SVC'}でSVM開く
# 学習
XORデータとXORラベルで学習。
# 予測
A=[[0, 0], [1, 1], [1, 0]]で予測
AをJSONエンコードして表示。
}}}
