▲INIとは

INI形式は、`[セクション]`と`キー=値`を並べて書く、シンプルな設定ファイルの書式です。gonakoの`plugin_ini`は、INI文字列と辞書を相互に変換します。本家TypeScript版にはない、gonako独自の命令です。

{{{#nako3(rows=12)
# INI文字列をパースする方法
データ=「
; コメント
name = なでしこ
[setting]
foo = 3
bar = 5
」
データをINI取得して、Ｆに代入。
ＦをJSONエンコード整形して表示。
### 表示結果: {
###   "name": "なでしこ",
###   "setting": {
###     "foo": "3",
###     "bar": "5"
###   }
### }
}}}

辞書をINI文字列として出力する例：

{{{#nako3(rows=10)
データ={"name":"なでしこ","setting":{"foo":3,"on":真}}
データをINI変換して表示。
### 表示結果: name=なでしこ
###
### [setting]
### foo=3
### on=true
}}}

▲注意 - 値はすべて文字列

`INI取得`は、値を数値や真偽値に変換しません。`007`のような先行ゼロや`on`などを、そのまま保つためです。この点で、数値へ自動変換する[[CSV取得:plugin_csv/CSV取得]]とは方針が異なります。数値として使うときは、`INT`や`変数を整数変換`などで変換してください。

▲取得の書式(INI取得)

- `[sec]`の下のキーは、`{sec: {key: val}}`の2段の辞書になります。セクションより前のキーは最上位に置かれます。
- 行頭(前後の空白を除く)が`;`または`#`の行はコメントです。行の途中の`;`や`#`は値の一部で、インラインコメントは扱いません。
- 値全体が`"`で囲まれているときは引用符を外し、中身(空白・`;`・`#`・`=`を含む)をそのまま値にします。
- `key = value`の前後の空白は除去します。`key=`は空文字列になります。
- 同じキーが重複したときは後の値が優先です。同じセクションが2回現れたときはマージします。
- キーやセクション名は大文字小文字を区別し、日本語も使えます。
- 改行はLF/CRLFの両方に対応し、先頭のBOMは除去します。`SJISファイル読`で読んだ文字列をそのまま渡せます。
- 閉じていない括弧`[sec`、空のセクション名`[]`、`=`のない行はエラーになります。

▲変換の書式(INI変換)

- 最上位の辞書のうち、スカラー値は`key=value`、辞書の値は`[name]`のセクションとして書き出します。セクションより前に書くキーが最上位になるため、最上位のスカラー値を先に、セクションを後に出力します(それぞれの中は辞書の順序を保ちます)。
- 値は、文字列はそのまま、数値は通常の数値表記、真偽値は`true`/`false`で書き出します。
- 前後に空白がある値や、全体が`"`で囲まれた値は、取得時に壊れないよう`"`で囲みます。
- セクションの中の辞書(2段より深い入れ子)、配列、null/undefined、改行を含む値はエラーになります(黙って落とすことはしません)。

▲利用例 - 設定ファイルの読み書き

{{{#nako3
設定=「[window]
title = なでしこ
width = 640」をINI取得。
(設定["window"]["title"])を表示。
(設定["window"]["width"]を整数変換して2倍)を表示。
### 表示結果: なでしこ
### 1280
}}}
