▲解説

INI文字列を辞書にして返します。`[セクション]`の下のキーは2段の辞書になります。値はすべて文字列です(数値への自動変換はしません)。

▲サンプル

{{{#nako3
T=「; 設定
name = なでしこ
[setting]
foo = 007
bar = 5
」のINI取得。
TをJSONエンコード整形して表示。
### 表示結果: {
###   "name": "なでしこ",
###   "setting": {
###     "foo": "007",
###     "bar": "5"
###   }
### }
}}}

▲サンプル - 引用符で囲んだ値

値全体を`"`で囲むと、空白や`;`、`#`、`=`を含む値をそのまま取得できます。

{{{#nako3
T=「memo = "  a;b#c=d  "」のINI取得。
「[」&T["memo"]&「]」を表示。
### 表示結果: [  a;b#c=d  ]
}}}

▲サンプル - 日本語のセクション名

{{{#nako3
T=「[表示]
色 = 赤」のINI取得。
(T["表示"]["色"])を表示。
### 表示結果: 赤
}}}

▲エラー

閉じていない括弧(`[sec`)、空のセクション名(`[]`)、`=`のない行は、`INI取得に失敗しました。…`というエラーになります。
